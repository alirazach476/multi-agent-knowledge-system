# Onboarding FAQ

Q: How do I get API access?
A: Request a key in the developer portal. Keys expire every 90 days.

Q: What model should I use for support bots?
A: Prefer gpt-4o-mini for routing and a stronger model for final drafting.

Q: Where are audit logs?
A: Audit logs are retained for 365 days under Admin > Security > Audit.
